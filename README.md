## 如何浏览产品目录

1. 打开网站首页，即可看到全部产品大类。
2. 点击任意分类卡片，进入该分类查看下面的子分类或产品表。
3. 继续点击，直到进入具体的产品表格，即可查看该类目下的所有产品及图片。
4. 顶部的 **搜索** 按钮可按产品名称或分类名称快速查找。
5. 页面顶部的 **面包屑导航** 与 **返回** 按钮，可随时回到上一级或首页。

> 提示：目录层级会自动展开，某个分类下若只有一个产品表，点击后会直接进入表格。
